The part core leaves to you
Nothing in register_post_status() adds your status to the editor’s Status dropdown or prints its name next to a post title. The classic editor needs a snippet of JavaScript in post_submitbox_misc_actions; the display label needs the display_post_states filter. Both are generated here.
The block editor
The block editor does not read post statuses registered in PHP at all. Custom statuses appear only through a plugin that registers them in JavaScript, or in the classic editor. The list-table filter link and display label do still work — which is often enough for an editorial workflow.
