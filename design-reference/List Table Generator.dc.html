The require nobody expects
if ( ! class_exists( 'WP_List_Table' ) ) { require_once ABSPATH . 'wp-admin/includes/class-wp-list-table.php'; }
WP_List_Table is not loaded on every admin request, and it is marked private in core. It has been stable for a decade, but that is a promise nobody made — pin the require and test after major releases.
Order matters in prepare_items()
Process bulk actions first, then fetch, then set_pagination_args, then assign $this->items. Setting items before pagination means the count is wrong; fetching before the bulk action means you display rows you just deleted.
Escaping
Nothing in this class escapes for you. Every column callback returns markup that goes straight into the page — so each one here escapes its own value, and the generated row_actions() output is built from esc_url() and esc_html().
