single changes the shape
With single true, get_post_meta() returns the value and REST exposes a scalar. With it false you get an array of every row for that key, and REST exposes an array — a difference that quietly breaks block code written against the other shape.
auth_callback
It defaults to a capability check on edit_post for the specific post, which is right. Override it only to tighten, never to loosen — a permissive auth_callback on a REST-exposed key lets any authenticated user write it.
